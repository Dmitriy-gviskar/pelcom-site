Pelcom Инфокиоск

Программная оболочка для сенсорных киосков и терминалов. Административная панель, управление контентом, интеграция с внешними системами, безопасный киоск-режим 24/7.

Возможности

Ключевые функции

Админ-панель

Веб-интерфейс управления контентом. Редактирование страниц, загрузка медиа, настройка меню без программирования.

Киоск-режим 24/7

Защита от выхода в ОС, блокировка нежелательных действий. Автоматический перезапуск при сбоях.

Интеграции

Подключение к 1С, CRM, платёжным системам, СКУД, AD/LDAP. API для внешних разработчиков.

Удалённое обновление

Централизованное обновление контента и ПО на всех устройствах. Расписание публикаций и версионирование.

Аналитика

Статистика посещений, популярные разделы, время взаимодействия. Экспорт в Excel и 1С.

Мониторинг

Отслеживание состояния всех киосков в реальном времени: онлайн, загрузка, ошибки, температура.
