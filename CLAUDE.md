# Пелком — правила репозитория

**Что это:** Статический сайт компании-производителя интерактивного оборудования (сенсорные киоски, панели, терминалы, LED-экраны, навигация, очередь, голография).

**Путь:** `/Users/dmitri/pelcom-site/` — git-репо, GitHub Pages: `dmitriy-gviskar.github.io/pelcom-site/`.

**Стек:** статический HTML/CSS/JS, без зависимостей. Чёрный фон (#000), шрифты Unbounded (заголовки) + Manrope (текст).

**Память:** `project_pelcom_site`, `project_pelcom_v4_redesign`.

## Железные правила

- **НЕ ПУТАТЬ основной сайт и v4-редизайн.** Основной сайт (`pelcom-site/`) — чёрный, Unbounded, в продакшене. v4 (`~/Desktop/pelcom-v4.html` и др.) — тёмно-синий (#0E1E36), Manrope, экспериментальный, НЕ деплоить.
- **Не выдумывать данные.** 99 моделей оборудования должны иметь свои уникальные спецификации, скопированные 1:1 с источника (BM Group). Не придумывать «По запросу» или шаблонные характеристики.
- **Не присваивать групповые характеристики моделям.** У каждой модели индивидуальные: диагональ, разрешение, ОС, ОЗУ, порты, вес, габариты.
- **Правки основного сайта:** редактировать в `~/Downloads/pelcom/` → копировать в `~/pelcom-site/` → коммит → пуш.
- **Правки v4:** редактировать на Desktop, в репо не пушить.
