Сферы применения

Где работают
LED-экраны Pelcom

01
Уличная реклама
Рекламные билборды на фасадах зданий, медиафасады, придорожные экраны. Удалённое управление расписанием показа, поддержка разных рекламодателей на одном экране.
02
Торговые центры
Видеостены в атриумах, рекламные стойки в переходах, информационные экраны у входов. Интеграция с системой управления рекламными площадями.
03
Спортивные объекты
Табло результатов и замены, медиаэкраны на трибунах, рекламные борта на поле. Синхронизация с трансляцией и системами хронометража.
04
Транспортные узлы
Информационные табло на вокзалах и аэропортах, рекламные поверхности в метро, навигационные экраны на парковках. Высокая яркость для засветлённых пространств.
Программное обеспечение

Управление контентом
на LED-экранах

LED-экраны Pelcom подключаются к Pelcom Мониторинг — системе централизованного управления контентом и мониторинга работы устройств.

Мониторинг
Pelcom Мониторинг

Система управления рекламным контентом для сети LED-экранов. Загрузка видео и изображений, настройка расписания показа, мониторинг яркости и температуры модулей, дистанционная диагностика.

  • Редактор плейлистов с временными слотами
  • Поддержка видео MP4, JPEG, PNG, GIF
  • Расписание по дням недели и датам
  • Мониторинг температуры панелей
  • Авторегулировка яркости по датчику
  • API для интеграции с рекламными системами
