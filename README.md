# Pelcom

Сайт компании-производителя интерактивного оборудования (сенсорные киоски, панели, системы самообслуживания, электронная очередь, навигация, LED-экраны, терминалы оплаты).

В корне сохранены исходники статического сайта для промежуточного просмотра на GitHub Pages. В `bitrix/` — полный перенос на «1С-Битрикс: Управление сайтом»: 134 страницы, 14 категорий, 99 моделей. Основной домен подготовленной версии — **https://pelcom-tech.ru**, подключение DNS отложено до выбора хостинга.

Инструкции: [локальная работа и архитектура](bitrix/README.md), [размещение и DNS REG.RU](DEPLOY.md). Ядро CMS, база, ключи и локальные пароли не хранятся в Git.
