# Pelcom

Сайт компании-производителя интерактивного оборудования (сенсорные киоски, панели, системы самообслуживания, электронная очередь, навигация, LED-экраны, терминалы оплаты).

Статический сайт — HTML/CSS/JS без зависимостей.

## Страницы

| Файл | Содержание |
|---|---|
| `pelcom-landing.html` | Главная: hero, каталог продуктов, отрасли, ПО, кейсы, отзывы, форма |
| `pelcom-about.html` | О компании |
| `pelcom-partners.html` | Дилерам |
| `pelcom-service.html` | Сервис 24/7 |
| `pelcom-kiosk.html` | Инфокиоски |
| `pelcom-panels.html` | Интерактивные панели |
| `pelcom-payment.html` | Терминалы оплаты |
| `pelcom-queue.html` | Электронная очередь |
| `pelcom-nav.html` | Навигация |
| `pelcom-led.html` | LED-экраны |

## Дизайн-система

- Шрифты: Unbounded (заголовки) + Manrope (текст)
- Цвета: `--blue:#0071e3`, `--black:#1A1A2E`, `--dark:#222238`, `--mid:#2C2C46`, `--cream:#F5F5F7`
