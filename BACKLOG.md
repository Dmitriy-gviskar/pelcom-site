# Pelcom — статус и задачи

Сверено с боевым сайтом и репозиторием 26.11.2026.

## Опубликовано

- [x] Сайт на Битриксе работает на REG.RU. Подключены DNS, HTTPS и перенаправления на основной адрес без `www`. [Порядок публикации](DEPLOY.md)
- [x] Опубликованы обновлённые главная, каталог и отраслевые решения. Первый экран главной использует рендер Pelcom 1661×935 из презентации заказчика. Боевой CSS ссылается на этот файл.
- [x] Опубликованы обновлённые «О компании», «Сервис», ПО и «Контакты», включая три страницы ПО. Боевые маршруты отвечают HTTP 200. В «Контактах» опубликован адрес в Дубне, карта подключена. Старый телефон-заглушка в боевом каталоге и пример почты на странице партнёров отсутствуют.
- [x] Опубликованы политика обработки персональных данных и отдельное согласие с реквизитами оператора. Обе ссылки подключены к формам на главной и в контактах. Метрика включается после согласия, есть отказ. Поля обеих форм размечены для скрытия в Вебвизоре.
- [x] Настроен серверный обработчик заявок на `info@pelcom-tech.ru`. Тесты двух форм подтвердили приём заявок почтовым транспортом. Проверка входящих указана отдельно ниже.
- [x] Добавлена проверка разрешения растровых изображений перед публикацией. Боевая сборка автоматически проверяет главную. Для точечных обновлений и внутренних страниц проверка выполняется на предпросмотре всех затронутых маршрутов. [Команда и параметры проверки](DEPLOY.md#проверка-разрешения-изображений)
- [x] Перепроверены старые замечания к SEO для опубликованных страниц. У всех 27 карточек в боевом sitemap есть Open Graph, Twitter Card и описание. В начале описаний не найдено удвоенных заглавных букв из старого аудита. В каталоге, решениях и ПО нужные поля Open Graph присутствуют. В выборке боевых страниц заголовки блоков подвала оформлены как `h3`.
- [x] `Pylon S` опубликован и включён в sitemap. У `Panel XL` описание и строка диагонали в исходной карточке указывают 75″. Боевая карточка `Panel XL` сейчас возвращает 404.

## Осталось

- [ ] **Подтвердить доставку обеих тестовых заявок** во входящие `info@pelcom-tech.ru`. Для подтверждения нужен доступ к ящику или отметка получателя.
- [ ] **Заменить изображения в блоке «Реализуем проекты под ключ».** На главной по-прежнему четыре вырезки 163×82, для которых действуют исключения проверки разрешения. Сопоставить кадры с презентацией Pelcom и подготовить превью с её оригиналами, если найдутся совпадения. Показать превью перед публикацией. Удалить соответствующие исключения после замены и повторной проверки.
- [ ] **Согласие в форме «Дилерам и партнёрам».** На `/partners/` есть обязательный чекбокс со ссылкой на политику. Добавить ссылку на отдельное согласие `/consent/` по образцу главной и контактов. Проверить валидацию и маскировку полей.
- [ ] **Фотографии и галереи каталога.** Получить у Pelcom фото для скрытых карточек моделей и реальные кадры для незаполненных галерей. После добавления фото пересмотреть публикацию нужных карточек. Например, `Pylon LED` сейчас возвращает 404 и отсутствует в sitemap. При его активации проверить появление в sitemap.
- [ ] **Другие изображения из списка исключений.** По мере появления исходников заменить оставшиеся малые вырезки на главной, в подвале, каталоге и разделе «О компании». [Текущие исключения](bitrix/image_resolution_exceptions.json)
