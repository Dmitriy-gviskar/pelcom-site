# Публикация сайта Пелком

Перед записью файлов на боевой сайт проверить разрешение изображений на всех страницах, затронутых публикацией, включая страницы, которые используют изменённый общий шаблон. Запускать `python3 bitrix/check_images.py --url <адрес предпросмотра> --path <маршрут>`. Для нескольких маршрутов повторять `--path`. Предпросмотр должен содержать подготовленную к загрузке разметку, стили и ресурсы. При ошибке исправить кандидата и повторить проверку до публикации.

Боевая сборка проверяет главную автоматически. При точечной загрузке через SSH/SFTP предзагрузочная проверка тоже обязательна. Порядок и параметры проверки описаны в `DEPLOY.md`.
